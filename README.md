# Breast Cancer Prediction Using Logistic Regression

## About the Project
This project focuses on predicting breast cancer using Machine Learning and the Logistic Regression algorithm. The model classifies tumors into two categories: **Malignant (Cancerous)** and **Benign (Non-Cancerous)**.

The main objective is to understand classification techniques and implement a predictive ML model.

## Objectives
- Understand and implement Logistic Regression.
- Perform data preprocessing.
- Prepare features for model training.
- Train and test the classification model.
- Evaluate model performance.

## Technologies & Libraries Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Algorithm
**Logistic Regression (Classification)**

Logistic Regression is a supervised machine learning algorithm used to predict categorical outcomes.

## Project Workflow
1. Import required libraries.
2. Load the breast cancer dataset.
3. Explore and analyze the dataset.
4. Perform data preprocessing.
5. Split data into training and testing sets.
6. Train the Logistic Regression model.
7. Make predictions.
8. Evaluate model performance.

## Evaluation Metrics
- Accuracy Score
- Confusion Matrix
- Precision
- Recall
- F1-Score
